# Workflow

Open **Workflow** in the sidebar. It holds the work a document moves through.

| Item | What it is for |
|---|---|
| Start workflow | Begin a workflow on a document |
| Inbox & outbox | Work waiting for you, and work you have sent on |
| Application folder | Each application, and whether it is approved, pending, rejected, or returned |
| Purchase Requisition | A non-trade request, from the draft through approval and delivery |

**Start workflow** is where a new run begins. **Inbox & outbox** is the list of runs already moving.

**Application folder** is the place to see an application and the step it is on.

**Purchase Requisition** opens the non-trade list. **New requisition** starts one. The filters are **Attention required**, **Waiting for Dept Head**, **BOCD**, **Accounting**, **Legal**, **Delivery documents**, and **Closed**. An empty list says **You're all caught up**.
