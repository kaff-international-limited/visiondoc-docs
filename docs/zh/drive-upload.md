# 上傳文件

<p>這頁有一段英文短片，字幕也是英文。<a href="../videos/12-upload-files.mp4">看短片</a></p>

**上傳文件** 是上面一排右邊的綠色按鈕。它把你選的檔案放進你打開的資料夾。可以一次選多於一個。英文畫面寫 **Upload files**。

也可以把檔案拖到頁面上。它們會進你打開的資料夾。

歸檔規則可以把檔案放到另一個資料夾。頁面會告訴你它最後放在哪，並寫出檔名、去了哪個資料夾，以及是哪一條規則放的。

例子：你在 **Home** 上傳 `invoice-104.pdf`。有一條規則把發票歸到 **Invoice**。頁面會說這份檔案在 **Invoice**，不在 **Home**。
