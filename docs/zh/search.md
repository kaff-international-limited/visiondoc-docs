# 搜尋

<p>這頁有一段英文短片，字幕也是英文。<a href="../videos/13-search.mp4">看短片</a></p>

側欄的 **搜尋** 會在頁面上面打開一個窗口。它搜整個工作區，不是只搜你打開的那個資料夾。

<figure class="shot">
  <img src="assets/search.png" alt="搜尋窗口，可以按檔名、內容或標籤">
  <figcaption>搜尋檔案庫。可以按檔名、內容或標籤。</figcaption>
</figure>

在 **搜尋檔名、內容或標籤…** 輸入。三個選項用來收窄：

| 選項 | 例子 |
|---|---|
| 檔名 | 輸入 `invoice`，找到檔名裡有 invoice 的文件 |
| 內容 | 找 PDF 裡面的字，就算檔名沒有寫那個字 |
| 標籤 | 找有人標了那個標籤的文件 |

方向鍵選一筆結果。**開啟** 打開它。**esc** 或者 **關閉** 收起窗口。

文件庫裡面的 **搜尋檔案…** 是另一個框。它只篩畫面上那個資料夾。
