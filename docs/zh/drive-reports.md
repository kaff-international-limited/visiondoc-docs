# 報表

<p>這頁有一段英文短片，字幕也是英文。<a href="../videos/09-reports.mp4">看短片</a></p>

**報表** 打開你正在看的資料夾的面板。標題是 **報表**。英文畫面寫 **Reports**。

一份已儲存的報表，是 VisionDoc 已經讀過的欄位組成的表。還沒儲存過的話，面板寫 **尚未有已儲存報表**。

| 控制 | 做甚麼 |
|---|---|
| 新增報表 | 開始一份報表 |
| 名稱 | 這份報表的名字 |
| 欄位 | 要變成直欄的欄位 |
| 儲存報表 | 留下這份報表。它要有名稱，而且至少一個欄位 |
| 執行 | 用已儲存的欄位填表。還沒執行的時候，面板寫 **按執行，用已擷取欄位填入表格。** |
| Excel | 把表下載成 Excel |
| CSV | 把表下載成 CSV |
| 電郵 | 把試算表寄出。填 **收件人**、**主旨**、**內容**，再按 **寄出試算表** |
| 刪除 | 拿掉那份已儲存的報表 |

例子：打開 **Invoice**，按 **報表**。名稱寫 `今年發票`，選發票編號、客戶和總額，再按 **儲存報表**。**執行** 填好那張表。**Excel** 把它下載下來。
