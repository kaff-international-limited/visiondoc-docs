**交件連結** 給你打開的資料夾做一條連結。公司外面的人可以用這條連結上傳，不用 VisionDoc 帳戶。可以在文件庫加檔案的人看得到這個按鈕。英文畫面寫 **Drop-off link**。

框的標題是 **交件連結**，後面是資料夾名稱。下面那行寫：對方無需登入，就可以把檔案上傳到這個資料夾。

| 按鈕 | 做甚麼 |
|---|---|
| 需要電子郵件一次性驗證碼 | 寄出驗證碼。客人輸入之後，連結才收檔案 |
| 有效時數 | 這條連結可以維持多久 |
| 上傳後要求電子簽署 | 上傳之後要求簽名。標題可以留空 |
| 建立連結 | 做出這條連結 |
| 複製網址 | 複製地址，方便你寄出 |
| 撤銷 | 關掉那條連結。已經上傳的檔案會留在文件庫 |

這個資料夾還沒有連結的話，框裡寫 **這個資料夾還沒有交件連結**。

打開 **Quotation**。按 **交件連結**。設定時數。按 **建立連結**，再按 **複製網址**。把地址寄給客戶。客戶上傳報價，不用先開帳戶。
