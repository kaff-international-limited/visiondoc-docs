# 交件連結

**交件連結** 做一條連到你打開的資料夾的連結。客人用這條連結上傳，不用 VisionDoc 帳戶。可以在文件庫加檔案的人看得到這個按鈕。英文畫面寫 **Drop-off link**。

框的標題是 **交件連結**，後面是資料夾名稱。下面那行寫：對方無需登入控制台，即可把檔案上傳到這個資料夾。

| 控制 | 做甚麼 |
|---|---|
| 需要電子郵件一次性驗證碼 | 把驗證碼寄出去。客人輸入之後，連結才收檔案 |
| 有效時數 | 這條連結可以維持多久 |
| 上傳後要求電子簽署 | 上傳之後要求簽名。標題可以留空 |
| 建立連結 | 做出這條連結 |
| 複製網址 | 複製地址 |
| 撤銷 | 關掉那條連結。已經上傳的檔案會留在文件庫 |

框裡列出這個資料夾仍然有效的連結。一條都沒有的話，寫 **這個資料夾還沒有交件連結**。

例子：打開 **Quotation**，按 **交件連結**，設定時數，**建立連結**，再 **複製網址**。把地址寄給客戶。客戶把簽好的報價上傳來，不用先開帳戶。
