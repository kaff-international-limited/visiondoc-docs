# 文件庫

**文件庫** 是文件放的地方。打開就在 **Home**。

左邊是資料夾清單。最上面的 **搜尋檔案…** 只篩你正在看的資料夾。側欄的 **搜尋** 搜整個工作區。

這張圖的清單有 **esign_signed**，然後 **Home**，然後 **inbox**。**Home** 打開了，所以下面是 **Invoice**、**Quotation**、**Sales Order**。Home 旁邊的 **1** 是這個資料夾裡選中了多少項。三個資料夾卡片下面的 **Folder**，繁體中文介面寫 **資料夾**。

## 上面一排

這些按鈕在資料夾名稱的右邊。在 Home，名稱就是 **Home**。Home 打開的時候，這一排沒有 **新增資料夾**。

| 按鈕 | 做甚麼 |
|---|---|
| 放大鏡 | **篩選**。打開一個框，提示是 **篩選檔名…**。**關閉** 清掉它。在這裡打字，和左邊的 **搜尋檔案…** 篩同一個資料夾 |
| 清單圖示 | 現在是卡片。按一下變成 **清單**。再按一下回到 **格狀** |
| 類型 | 按類型排序。箭嘴向上是 **類型 A→Z**，向下是 **類型 Z→A**。英文畫面寫 **Type** |
| 貼上 | 把複製或剪下的項目放進你正在看的資料夾。剪貼簿是空的時候，這個按鈕是灰的 |
| 報表 | 打開這個資料夾的 **報表**。填 **名稱**、選 **欄位**，再按 **儲存報表**。**執行** 用已擷取的欄位填一張表。然後可以 **Excel**、**CSV**，或 **電郵** |
| 交件連結 | 一條連結，沒有 VisionDoc 帳戶的人也可以把檔案上傳到這個資料夾。可以在文件庫加檔案的人看得到這個按鈕。英文畫面寫 **Drop-off link** |
| 上傳資料夾 | 把電腦上的整個資料夾上傳到你打開的資料夾 |
| 上傳文件 | 綠色按鈕。把你選的檔案上傳到你打開的資料夾。英文畫面寫 **Upload files** |

也可以把檔案拖到頁面上。它們會進你打開的資料夾。

歸檔規則可以把檔案放到另一個資料夾。頁面會告訴你它最後放在哪。

## 選中檔案之後

選中一個檔案或資料夾，下面多出一排。只選一項的時候，左邊的按鈕顯示檔名。小箭嘴打開清單，這個按鈕的標題是路徑。多過八項的時候，清單上面有一個搜尋框，這句仍然是英文：**Find in selection**。清單裡每一行的 ✕ 拿掉那一項。同一個資料夾裡選了多個檔案，這個按鈕顯示數目，例如 **已選 3 項**。

| 按鈕 | 做甚麼 |
|---|---|
| 檔名按鈕 | 選中的檔案。這張圖是一份 PDF |
| 複製 | 複製它。頁面叫你打開一個資料夾再按 **貼上**。原本那份留在原位。之後的 **貼上** 在你打開的資料夾放一份新的。英文畫面寫 **Copy** |
| 移動至… | 剪下它。頁面叫你打開一個資料夾再按 **貼上**。之後的 **貼上** 把項目移進那個資料夾。英文畫面寫 **Move to…** |
| 貼上 | 和上面一排的貼上是同一個 |
| 刪除 | 先問一次。檔案的問題會寫出檔名，並問是不是把檔案移至 rejected（軟刪除）。確認之後，檔案移到 rejected。**Home**、**Invoice**、**Quotation**、**Sales Order** 不能刪。頁面寫 **系統資料夾（inbox、approved…）無法刪除。** 可以刪的資料夾會連裡面的東西一起刪走，而且不能復原 |
| 重新命名 | 只選中一項，而且不是 **Home**，才會出現。對話框標題是 **重新命名**，問 **新檔名：**。英文畫面寫 **Rename** |
| 下載 | 把檔案存到你的電腦 |
| 匯出 | 打開選單。**CSV（.csv）** 和 **Excel（.xlsx）** 是 VisionDoc 已經讀過的檔案的擷取欄位。選中的檔案都還沒讀過的話，頁面寫 **請選擇已處理的文件。** 英文畫面的按鈕是 **Export** |
| 權限 | 只選中一項才出現。打開那份檔案或那個資料夾的 **資料夾權限**。英文畫面寫 **Permissions** |
| 重新讀取資料夾 | 公司管理員看得到。面板標題是 **重新讀取這個資料夾**。它數這個資料夾和下面所有資料夾裡的文件。**重新讀取** 會換掉文字、分類、抽取欄位和標籤。背後沒有文件記錄的檔案可以先收回來。那個按鈕會寫出要收回多少個檔案。每一頁都會再讀一次。**取消** 關掉面板。英文畫面的按鈕是 **Re-read folder** |
| 詢問這些文件 | 綠色按鈕。把選中的檔案交給助手。它們都還沒讀過的話，頁面寫 **請選擇已處理的文件。** 英文畫面寫 **Ask about these** |
| ✕ | **取消全選**。第二排消失 |

選中兩份或更多 VisionDoc 已經讀過的檔案，**AI 重新命名** 會出現在 **重新命名** 和 **下載** 之間。它先顯示建議的檔名。你確認之前不會改名。這張圖只選了一份檔案，所以這一排沒有這個按鈕。英文畫面寫 **Rename with AI**。

## 資料夾結構

**Home** 是主資料夾，放在文件庫裡面。公司一開始，Home 裡面有三個資料夾。每一家公司都是這個結構。

| 資料夾 | 位置 | 規則 | 例子 |
|---|---|---|---|
| Home | 在文件庫 | 根資料夾。不能刪，也不能改名 | 打開文件庫就在這裡 |
| Invoice | 在 Home | 不能刪 | 那張訂單的發票 |
| Quotation | 在 Home | 不能刪 | 營業員寄給客戶的報價 PDF |
| Sales Order | 在 Home | 不能刪 | 客戶確認之後的銷售訂單 |

可以在 **Invoice**、**Quotation**、**Sales Order** 裡面開多少個資料夾都可以。打開這三個其中一個，上面一排就有 **新增資料夾**。對話框標題是 **新建資料夾**。名稱用英文字母、數字、- 和 _。**建立** 就開好。例如 `Quotation / 2026` 放今年的報價，`Invoice / 2026` 放今年的發票。

不能在 **Home** 裡面再開另一個資料夾，也不能在 **Home** 旁邊開一個新的。這句在繁體中文介面仍然是英文：**This folder level is fixed. Add a subfolder under Invoice, Quotation, Sales Order.**

## 給客人的連結

**交件連結** 打開一個框，標題是 **交件連結**，後面是你打開的資料夾名稱。下面那行寫：對方無需登入控制台，即可把檔案上傳到這個資料夾。

**需要電子郵件一次性驗證碼** 會把驗證碼寄出去，客人輸入之後連結才收檔案。**有效時數** 是這條連結可以維持多久。還有 **上傳後要求電子簽署**，標題可以留空。**建立連結**，然後 **複製網址**。**撤銷** 關掉那條連結。已經上傳的檔案會留在文件庫。框裡會列出這個資料夾仍然有效的連結。一條都沒有的話，寫 **這個資料夾還沒有交件連結**。

例子：打開 **Quotation**，按 **交件連結**，設定時數，把網址寄出去。客戶把簽好的報價上傳來，不用先開帳戶。已經在 Home 的 PDF 也一樣：選中它，按 **移動至…**，打開 **Quotation**，再按 **貼上**。
