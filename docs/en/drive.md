## When you select a file

Select a file or a folder and a second row appears. One item shows its name. The arrow opens the list. With more than eight items, that list has a box that says **Find in selection**. The ✕ on a row removes that one item. Several files in the same folder show a count, such as **3 selected**.

| Button | What it does |
|---|---|
| The file name | The selected file. In this picture it is one PDF |
| Copy | Copies it. Open a folder and click **Paste**. The original stays. **Paste** puts a new copy in the folder you have open |
| Move to… | Cuts it. Open a folder and click **Paste**. The file moves into that folder |
| Paste | The same paste as the top row |
| Delete | Asks first. For a file, it asks to move it to rejected. Confirm, and the file moves to rejected. **Home**, **Invoice**, **Quotation**, and **Sales Order** cannot be deleted. The page says **System folders (inbox, approved, …) cannot be deleted.** A folder you are allowed to delete is removed with everything inside it, and that cannot be undone |
| Rename | Shows when exactly one item is selected, and that item is not **Home**. The box is titled **Rename** and asks **New file name:** |
| Download | Saves the file to your computer |
| Export | Opens a menu. **CSV (.csv)** and **Excel (.xlsx)** are the details VisionDoc has already read. If none of the selected files have been read, the page says **Select documents that have been processed.** |
| Permissions | Shows for one item. Opens **Folder permissions** for that file or folder |
| Re-read folder | People who manage the company see this. The panel is titled **Re-read this folder**. It counts the files in this folder and in the folders under it. **Read them again** replaces their text, labels, details, and tags. **Cancel** closes the panel |
| Ask about these | The green button. Sends the selected files to Ask. If none of them have been read, the page says **Select documents that have been processed.** |
| ✕ | Clears the selection. The second row goes away |

Select two or more files that VisionDoc has already read, and **Rename with AI** appears between **Rename** and **Download**. It shows a suggested name for each file. Nothing is renamed until you confirm. This picture has one file selected, so that button is not showing.

## The folders

Every company starts with the same folders.

| Folder | Where | What you can do | Example |
|---|---|---|---|
| Home | In Drive | You cannot delete it or rename it | The folder you land in |
| Invoice | In Home | You cannot delete it | The bill for an order |
| Quotation | In Home | You cannot delete it | The PDF a salesperson sends to a customer |
| Sales Order | In Home | You cannot delete it | The confirmed order that follows that quotation |

You can add folders inside **Invoice**, **Quotation**, and **Sales Order**. Open one of those three and **Add folder** is in the top row. The box is titled **New folder**. The name can use letters, numbers, hyphens, and underscores. **Create** makes it. For example, `Quotation / 2026` holds this year's quotations.

You cannot add a folder directly inside **Home**, and you cannot add a folder next to **Home**. The page says **This folder level is fixed. Add a subfolder under Invoice, Quotation, Sales Order.**

How long a file stays is a separate page, [Retention](retention.md).
