**Paste** puts a copied or cut file into the folder you have open. The button is in the top row, and again in the row that appears when you select something. It stays grey until you have copied or cut something.

**Copy** leaves the original where it is. Open the folder you want, then click **Paste**. You get a new copy there.

**Move to…** cuts the file. Open the folder it should go to, then click **Paste**. The file moves. The page tells you how many files were cut, and to open a folder and click **Paste**.
