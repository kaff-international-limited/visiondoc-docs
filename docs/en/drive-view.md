# List and grid

<p><a href="../videos/06-list-and-grid.mp4">Watch the video</a></p>

Drive opens as cards. A folder card says **Folder**. A PDF card says **PDF**.

The button beside **Type** switches the view. The picture is the card view, so the icon is the list. Click it and the same files become a **List**. Click it again for **Grid**.
