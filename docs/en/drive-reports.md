# Reports

<p><a href="../videos/09-reports.mp4">Watch the video</a></p>

**Reports** opens a panel for the folder you have open. The title is **Reports**.

A saved report is a table of the fields VisionDoc has already read. If you have not saved one, the panel says **No saved reports yet**.

| Control | What it does |
|---|---|
| New report | Starts a report |
| Name | The name of the report |
| Columns | The fields that become columns |
| Save report | Keeps the report. It needs a name and at least one column |
| Run | Fills the table from the stored fields. Until you run it, the panel says **Run the report to fill the table from stored fields.** |
| Excel | Downloads the table as Excel |
| CSV | Downloads the table as CSV |
| Email | Sends the spreadsheet. You fill **To**, **Subject**, and **Message**, then **Send spreadsheet** |
| Delete | Removes that saved report |

Example: open **Invoice** and click **Reports**. Name it `Invoices this year`, pick the invoice number, the customer, and the total, then **Save report**. **Run** fills the table. **Excel** downloads it.
