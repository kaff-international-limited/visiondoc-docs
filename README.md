# VisionDoc how-to

This repository is the public how-to for VisionDoc. The English pages are in `docs/en/` and the Traditional Chinese pages are in `docs/zh/`. `docs/LANGS.md` is the language list. GitBook Git Sync reads the English book.

The published site is built from those pages with [HonKit](https://github.com/honkit/honkit), which renders a GitBook book.

Production console: https://app.visiondoc.ai
